# Bank-scoring-model
Une société financière souhaite accorder des crédits à la consommation pour des personnes ayant peu ou pas d'historique de prêt. Pour cela, l'entreprise calcule la probabilité qu'un client le rembourse, ou non. Elle souhaite donc développer un algorithme de scoring interprétables.

- Objectif : utiliser Jupyter Notebook et Scikit-Learn pour créer, évaluer et améliorer un modèle de scoring basé sur les données des clients.
- Données : Pour le projet nous utilisons la base de données relative à une compétition kaggle https://www.kaggle.com/competitions/home-credit-default-risk/data
